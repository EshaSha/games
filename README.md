# Мои игры

Одностраничный сайт-коллекция игр в Steam: обложки, статус, оценка, часы и короткие заметки. Без сборки и зависимостей — чистые HTML, CSS и JavaScript, хостинг на GitHub Pages.

## Данные

Список собран из Steam Web API: 96 игр, 18+ тайтлы исключены. Часы и статусы проставлены автоматически: `playing` — игра запускалась за последние две недели, `played` — есть наигранные часы, `backlog` — 0 часов. Оценки и заметки пустые — их можно заполнить вручную в `games.js`.

## Как добавить игру

1. Открой страницу игры в Steam. Цифры в адресе — это `appid`:
   `https://store.steampowered.com/app/1145360/` → `1145360`.
2. Открой файл `games.js` и добавь объект в массив `GAMES`:

```js
{
  appid: 1145360,
  title: "Hades",
  status: "completed",
  rating: 5,
  hours: 62,
  genres: ["Рогалик", "Экшен"],
  note: "Короткое впечатление об игре."
}
```

### Поля

| Поле     | Обязательно | Описание |
| -------- | ----------- | -------- |
| `appid`  | да          | ID игры в Steam. По нему автоматически подгружается обложка и ссылка на магазин. |
| `title`  | да          | Название игры. |
| `status` | да          | `playing` — играю, `played` — играл(а), `completed` — пройдено, `backlog` — в планах, `dropped` — брошено. |
| `rating` | нет         | Оценка от 0 до 5. `0` — без оценки. |
| `hours`  | нет         | Наигранные часы, число. |
| `genres` | нет         | Массив жанров или тегов. |
| `note`   | нет         | Пара предложений впечатлений. |

Обложки берутся с CDN Steam: `library_600x900.jpg`, а если вертикальной обложки нет — `header.jpg`. Если картинка не загрузилась, показывается заглушка с первой буквой названия.

## Публикация изменений

После правки `games.js`:

```sh
git add .
git commit -m "Обновил список игр"
git push
```

GitHub Pages обновит сайт автоматически в течение минуты. Править `games.js` можно и прямо на GitHub: открой файл → карандаш → Commit changes.

## Локальный просмотр

```sh
python3 -m http.server 8000
```

Затем открой `http://localhost:8000`.
