# Список игр

Одностраничный сайт со списком игр для выбора на следующий стрим. У каждой игры есть обложка, жанры, наигранные часы и кнопка «Копировать», которая копирует название в буфер обмена. Без сборки и зависимостей — чистые HTML, CSS и JavaScript, хостинг на GitHub Pages.

## Данные

Список собран из Steam Web API: 88 игр. Исключены 18+ тайтлы, VR-игры, программы (например, Blender и Wallpaper Engine) и приложения для продуктивной работы. Обложки и жанры подгружаются по `appid`, часы взяты из профиля Steam.

## Как добавить игру

1. Открой страницу игры в Steam. Цифры в адресе — это `appid`:
   `https://store.steampowered.com/app/1145360/` → `1145360`.
2. Открой файл `games.js` и добавь объект в массив `GAMES`:

```js
{
  appid: 1145360,
  title: "Hades",
  hours: 62,
  genres: ["Рогалик", "Экшен"],
  note: "Короткое впечатление об игре."
}
```

### Поля

| Поле     | Обязательно | Описание |
| -------- | ----------- | -------- |
| `appid`  | да          | ID игры в Steam. По нему подгружается обложка и ссылка на магазин. |
| `title`  | да          | Название игры — именно оно копируется кнопкой. |
| `hours`  | нет         | Наигранные часы, число. |
| `genres` | нет         | Массив жанров или тегов. |
| `note`   | нет         | Пара предложений впечатлений. |

Обложки берутся с CDN Steam: `library_600x900.jpg`, а если вертикальной обложки нет — `header.jpg`. Если картинка не загрузилась, показывается заглушка с первой буквой названия. Клик по обложке или названию открывает страницу игры в Steam.

## Публикация изменений

После правки `games.js`:

```sh
git add .
git commit -m "Обновил список игр"
git push
```

GitHub Pages обновит сайт автоматически в течение минуты. Править `games.js` можно и прямо на GitHub: открой файл → карандаш → Commit changes.

## Локальный просмотр

```sh
python3 -m http.server 8000
```

Затем открой `http://localhost:8000`.
